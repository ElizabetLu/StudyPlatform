# Study Platform

A console-based study management platform built with C# and .NET.

## Description

Study Platform allows users to register, log in, manage profiles, create notes, generate flashcards, manage study tasks, and track learning progress. The application also includes admin functionality, role-based access, login event tracking, and JSON-based data storage.

## Technologies Used

- C#
- Object-Oriented Programming
- Async/Await
- JSON File Storage
- File I/O
- LINQ
- Password Hashing
- Role-Based Access
- Console Application Architecture

## My Role

I designed and implemented the full application structure, including models, business logic, menu navigation, authentication, user/admin functionality, JSON storage classes, notes, flashcards, study tasks, and progress tracking.
